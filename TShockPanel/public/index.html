快速上手

  1. 在「世界存档」里选择一个现有世界，或新建一个世界。
  2. 回到「仪表盘」，设置端口与人数后点击「启动服务器」。
  3. 服务器启动后，玩家用你的局域网 IP 或公网 IP 连接 端口 7777。
  4. 第一次成为服主：进游戏后输入聊天命令 /setup 认证码，认证码显示在仪表盘上。
  5. 需要改规则时到「服务器设置」，保存后点击「重启」生效。

常见问题

朋友连不上怎么办？

依次检查：服务器是否运行、端口是否填写一致、Windows 防火墙是否放行了 TShock.Server.exe、路由器是否做了端口转发（外网联机）。

控制台命令为什么没有回显？

命令通过 TShock 的 REST 接口执行，返回值会直接显示在控制台。世界里发生的事情仍然会出现在日志区。

修改设置后为什么不生效？

绝大多数设置需要重启服务器才会重新读取。

存档在哪里？

默认为 文档\My Games\Terraria\Worlds，也可以在「面板设置」里改成服务器目录下的其它位置。

面板安全吗？

面板只监听 127.0.0.1，不会暴露到局域网；REST 端口则可能被局域网访问，密码与令牌请不要外传。

关于

TShock 管理面板 1.0.0

一个零依赖的本地网页面板，用来启动/停止泰拉瑞亚 TShock 服务器、管理世界与备份、修改配置、查看日志与玩家。

服务器程序、存档与配置均保持原有格式，面板只是为其提供一个图形界面。
